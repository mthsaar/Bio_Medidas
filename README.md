# Bio-medidas
Body measurements made easy.

## About the software
Bio-medidas is a software designed with health professionals in mind, the goal is to easily generate human measurements.

## The problem
You are attending an patient with some disability, or in pain and have to use the measurements you can evaluate to 
generate others, such as BMI, height, body fat index. 
With this app you can type what you can measure and the app will take care of the rest.
